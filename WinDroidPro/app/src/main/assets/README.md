# Assets

This directory contains binary assets required for WinDroid Pro.
In a real deployment, these files should be replaced with actual compressed binaries.

## Required Files:
- wine-9.0-x86.tar.xz: Wine 9.0 (32-bit)
- wine-9.0-x86_64.tar.xz: Wine 9.0 (64-bit)
- box64.tar.xz: Box64 emulator
- mesa.tar.xz: Mesa graphics drivers (Turnip/Zink)
- dxvk.tar.xz: DXVK translation layer
- vkd3d.tar.xz: VKD3D translation layer

Currently, these are empty placeholders for development and structural verification.
